# Casa Vendrell

Aplicación web fullstack para el bar de vinos Casa Vèndrell en Barcelona.

## Stack tecnológico
- **Frontend:** React + TypeScript + Tailwind CSS + React Router
- **Backend:** Node.js + Express
- **Base de datos:** MySQL
- **Despliegue:** Vercel
