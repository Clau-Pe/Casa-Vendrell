# CASA VENDRELL — Idea del proyecto

## ¿Qué problema resuelve?
Casa Vendrell es un bar de vinos en Barcelona que necesita una presencia digital profesional. Actualmente no tiene web, por lo que, además de estar perdiendo presencia y posicionamiento digital, los clientes no pueden consultar la carta, hacer reservas ni conocer los eventos antes de visitar el local. A su vez consta de una carta muy dinmámica que requiere un panel de administrador para poder actualizar los datos que se visualizan en esa carta.

## Usuario objetivo
Dos perfiles de usuario:
- **Cliente:** persona interesada en visitar el bar, consultar la carta de vinos y tapas, ver eventos y hacer reservas online.
- **Administrador:** socio del bar que necesita gestionar la carta.

## Funcionalidades principales
- Página de inicio con presentación del bar
- Historia del bar y el equipo
- Carta de vinos y tapas con precios
- Sección de eventos
- Sección Consultoria
- Formulario de reservas
- Panel de administrador con login
- Gestión de carta y precios desde el panel
- Gestión de eventos.
- Gestión de reservas.

## Funcionalidades opcionales
- Multiidioma (castellano, inglés, catalán)
- Galería de fotos
- Integración con Google Maps
- Notificaciones al whatsapp al hacer una reserva.
- Notificaciones al email por consultoría o suscripción al newsteller.

## Posibles mejoras futuras
- App móvil
- Sistema de fidelización de clientes
- Integración con redes sociales
- Pasarela de pago para reservas con depósito

## Stack tecnológico
- **Frontend:** React + TypeScript + Tailwind CSS + React Router
- **Backend:** Node.js + Express
- **Base de datos:** PostgreSQL
- **Despliegue:** Vercel
