# GESTION DEL PROYECTO - CASA VENDRELL

## METODOLOGIA
Se utiliza Kanban como metodología de gestión del proyecto. Se eligió Kanban sobre Scrum porque el proyecto es desarrollado por una sola  persona y no requiere sprints ni ceremonias formales. Kanban permite visualizar el flujo de trabajo y limitar el trabajo en progreso de  forma flexible.

## TABLERO KANBAN
El tablero se gestiona en Trello con las siguientes columnas:

- **Backlog:** todas las tareas pendientes del proyecto
- **Todo:** tareas seleccionadas para trabajar próximamente
- **In Progress:** tareas en desarrollo activo (máximo 2-3 a la vez)
- **Review:** tareas terminadas pendientes de revisión o validación
- **Done:** tareas completamente terminadas y probadas
